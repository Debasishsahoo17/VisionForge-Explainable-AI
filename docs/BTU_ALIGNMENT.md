# Why this project is relevant to BTU Artificial Intelligence M.Sc.

VISIONFORGE is an independent applicant portfolio project. It is **not** coursework undertaken at BTU, nor is it affiliated with or endorsed by the university. Curriculum alignment is based on its **official summer semester 2026 module handbook**, not an admission guarantee.

| BTU module | Verified project evidence | Boundaries |
|---|---|---|
| **14186 Image Processing and Computer Vision** | Digital images, convolutional filters and learned visual representations; classifying image patterns | This pilot does not implement optical flow, tracking or segmentation |
| **11847 Neural Networks and Learning Theory** | CNN architecture from scratch, residual network training and empirical generalization/validation tracking | Does not prove theorems about generalization |
| **14021 Explainable Machine Learning** | Two genuine class-specific Grad-CAM implementations, attribution gallery and failure interpretation | Spatial saliency does not establish causality |
| **14449 Workflows for Machine Learning and Reproducible Science Laboratory** | Recorded hyperparameters, fixed seeds, held-out test set, stored predictions, CI tests and GitHub Actions | One seed/split is not enough for robust general conclusions |
